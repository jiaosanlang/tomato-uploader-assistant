【Tomato Uploader Assistant】使用说明
========================================

▎源码安装
  1. 安装 Node.js 20 或更高版本
  2. 在项目目录运行 npm install
  3. 运行 npx playwright install chromium
  4. 双击 start.bat，或运行 npm start

▎打开程序
  程序默认访问 http://127.0.0.1:4321
  关闭命令行窗口后，本地服务会停止。

▎Chrome 扩展读取正文目录
  1. 先双击 start-extension-helper.bat，并保持窗口运行
  2. 在扩展中设置“从第几章开始”
  3. 点击“选择正文目录”，在系统窗口中选择文件夹
  4. 目录由本地助手扫描，Chrome 不会直接加载整个目录

  禁止把扩展改回 webkitdirectory 或 showDirectoryPicker 直接读取目录，
  这两种方式在部分 Windows/Chrome 环境中可能造成整个浏览器崩溃。

▎第一次使用
  1. 进入网页的「设置」页面
  2. 选择整本 TXT 或存放分章 TXT 的正文目录
  3. 填写自己的番茄作品上传页地址
  4. 点击「登录」并在打开的浏览器中完成登录
  5. 解析小说、生成排期并核对结果
  6. 在「上传」页面处理下一章

▎本地文件
  · config.json 保存本机配置和作品页面地址
  · profile 文件夹保存浏览器登录资料
  · state.json 保存上传进度
  · schedule.json 保存排期结果

这些文件都已加入 .gitignore，请勿手动上传到公开仓库。

▎使用提醒
  请仅上传自己拥有合法权利的内容，并遵守平台规则。
  遇到验证码、登录验证或风控提示时，请暂停并由用户完成操作。
  小说正文只会在用户主动提交章节时发送到番茄作者后台。

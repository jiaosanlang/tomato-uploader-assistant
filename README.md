# Tomato Uploader Assistant

一款本地运行的番茄小说章节上传辅助工具。

项目可以读取整本 TXT 文件或分章目录，识别卷名、章节标题和正文，根据每日字数、章节数量与发布时间生成排期，并通过可视化页面协助完成番茄作者后台上传。上传进度保存在本地，任务中断后可以继续处理。

当前版本使用 Node.js、Playwright 和 Chromium，主要面向 Windows 环境。项目仍处于早期开发阶段，现阶段优先保证章节内容、发布时间和提交结果能够人工核对。

## 当前功能

1. 支持整本 TXT 文件与分章 TXT 目录
2. 自动识别卷名、章节标题和正文
3. 自动统计章节字数
4. 根据每日字数、章节数量和发布时间生成排期
5. 通过本地网页查看配置、章节、排期和上传日志
6. 保存浏览器登录状态
7. 校验章节提交结果并保存上传断点
8. 跳过已经完成的章节
9. 采用单章安全模式，方便每次上传后前往后台核对

## Chrome 侧边栏扩展（实验版）

`extension/` 目录包含 Manifest V3 侧边栏扩展的第一版。它可以在 Chrome 侧边栏中选择 TXT、解析章节、生成排期，并识别或填写当前打开的番茄作者后台章节编辑页。

扩展暂时不会替你点击“下一步”或“发布”。填写完成后，请人工核对章节内容、发布时间和页面提示，再由你自己提交。

安装方式：

1. 打开 `chrome://extensions/`
2. 打开右上角的“开发者模式”
3. 点击“加载已解压的扩展程序”
4. 选择本仓库的 `extension` 文件夹
5. 固定扩展图标，打开侧边栏开始使用

扩展只申请当前页面、侧边栏和本地存储权限，并限定在番茄相关域名运行。

## 安装要求

1. Windows 10 或 Windows 11
2. Node.js 20 或更高版本
3. 可以正常访问番茄作者后台的网络环境

## 安装与启动

克隆仓库后进入项目目录。

```powershell
git clone https://github.com/jiaosanlang/tomato-uploader-assistant.git
cd tomato-uploader-assistant
npm install
npx playwright install chromium
```

使用下面任意一种方式启动。

```powershell
npm start
```

也可以在 Windows 中双击 `start.bat`。程序启动后会打开本地页面。

```text
http://127.0.0.1:4321
```

首次启动时，程序会使用安全的默认配置。进入设置页面选择小说文件或正文目录，填写番茄后台上传页地址，保存后会在本地生成 `config.json`。

## 基本使用流程

1. 在设置页面选择整本 TXT 或分章目录
2. 填写自己的番茄作品上传页地址
3. 打开登录窗口并完成登录
4. 解析小说并检查章节标题和字数
5. 生成发布排期并核对日期与时间
6. 开始上传下一章
7. 前往番茄作者后台确认章节和定时发布状态

## 本地数据

下列内容不会提交到 Git 仓库。

1. `config.json` 保存本机路径和作品页面地址
2. `profile/` 保存浏览器登录资料
3. `state.json` 保存上传进度
4. `schedule.json` 保存生成的排期
5. `node/` 和 `browsers/` 用于便携版本的本地运行时

小说正文、配置、浏览器登录资料和上传进度均保存在本机。程序只在用户主动提交章节时将正文发送到番茄作者后台，本项目没有额外的数据收集服务。

## 项目结构

```text
engine.mjs          Playwright 上传与结果校验
parse.js            TXT、卷和章节解析
schedule.js         发布排期计算
server.mjs          本地网页服务与接口
web/                可视化操作页面
extension/          Chrome Manifest V3 侧边栏实验版
config.example.json 安全的配置示例
start.bat           Windows 启动脚本
```
